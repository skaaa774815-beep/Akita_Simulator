・アプリ名
秋田県知事シミュレーション

・アプリの簡単な概要
県民の期待に応えるために、季節ごとに発生するトラブルを対処していくシミュレーションゲームです。
プレイヤーは秋田県知事となり、「県民満足度」「人口」「発展度」「予算」を管理しながら、AIを活用した施策実行で地域課題の解決を目指します。

・主な機能
- 行政運営シミュレーション（パラメータ管理機能）
- プレイ期間選択機能（1〜10年、エンドレスモード）
- 定期イベント（30日ごとの交付税収入・人口変動、季節の進行）
- 任期審査システム（90日ごとの実績評価、未達の場合は退任）
- プレイヤーによる自由記述施策のAI動的評価（入力された対策案を生成AIがリアルタイムに分析・評価）
- 複数AI自動フォールバック機構（通信エラー時にGemini/Cohere/Groq/Mistralを自動切り替え）

・動作環境と使用言語（バージョン含む）
動作環境: Visual Studio Code (1.130.0), Thonny (1.0.0.1)
使用言語: Python (3.x 開発時 3.14)

・必要なライブラリ（バージョン含む）
pygame (2.6.1) ※環境によっては pygame-ce
requests (2.34.2)
※マップ生成・処理用: shapely, numpy

・インストール方法
1. 以下のGitHubリンクから任意の.zipファイルをダウンロードし、PC内の適当なフォルダに解凍（展開）してください。
https://github.com/skaaa774815-beep/Akita_Simulator
2. 解凍後、使用する各種生成AIのAPIキーをご自身で取得し、同梱の「config.txt」に貼り付けて保存してください。

・起動方法
お使いの動作環境（VS CodeやThonnyなど）で解凍したフォルダを開き、メインプログラムを実行してください。

・基本的な操作方法
マウス: 画面左側のコントロールパネルでのボタンクリック、選択肢の決定など
キーボード: 施策入力時のテキストタイピング

・使用時の注意事項
- 施策のAI評価システムを利用するため、プレイ中は安定したインターネット接続が必須となります。
- 学校や企業などのネットワーク環境（プロキシ制限など）によっては、API通信エラーが発生する場合があります。
- 各種APIキーは無料で取得可能ですが、サービスによってはクレジットカード等の登録（従量課金設定など）を求められる場合がありますので、登録時の規約や設定内容には十分ご注意ください。

・既知の不具合
- 生成AIのAPI提供側のアクセス制限や混雑状況により、評価結果が返ってくるまでに数秒〜十数秒の遅延が発生する場合があります。

・使用した外部素材、データ、API 等の名称、出典、ライセンス
【生成AI API】Gemini API, Cohere API, Groq API, Mistral API
【データ】秋田県の行政区域データ (GeoJSON)
【開発ツール】Tiled (2Dマップエディタ), ペイント
